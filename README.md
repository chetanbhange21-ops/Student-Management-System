# Student Management System

**Backend Project by Chetan Bhange**

A REST API-based Student Management System built using Java, Spring Boot, Spring Data JPA, Hibernate and MySQL.

## Features

- Create student records
- Retrieve student details
- Update student information
- Delete student records
- DTO-based request and response handling
- Layered architecture using Controller, Service and Repository

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST APIs

## Project Structure

- `controller` – Handles HTTP requests
- `service` – Contains business logic
- `repository` – Handles database operations
- `entity` – Student entity
- `dto` – Request and response objects

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure your MySQL database.
4. Set database credentials in `application.properties`.
5. Run the Spring Boot application.
